# OTT Subscription Optimizer

## Overview

OTT Subscription Optimizer is an AI-powered decision support system that recommends the optimal combination of OTT subscriptions based on a user's viewing preferences, subscription budget, and content availability across streaming platforms.

## Tech Stack

- Python
- TMDB API
- Google Cloud Platform (GCP)
- BigQuery
- Cloud Storage
- Gemini API
- Streamlit
- Cloud Run

## Project Structure

```
app/               # Streamlit application
ai/                # Gemini integration
recommendation/    # Recommendation engine
scripts/           # Data collection & preprocessing
sql/               # BigQuery SQL
data/              # Raw & processed data
docs/              # Project documents
```# ott-subscription-optimizer
AI-powered decision support system for optimizing OTT subscription combinations based on user preferences, content coverage, and subscription costs.
